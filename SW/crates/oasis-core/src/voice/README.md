# `oasis-core/src/voice/` — voice session rules

## Overview
**What:** the lifecycle of one push-to-talk utterance (idle → capturing → busy → idle), the
rule for pausing media while you speak, and the voice safety invariants.

**Why:** the C# `VoiceSessionService` tracked this with loose booleans (`_capturing`, `_busy`,
`_dictateThisUtterance`…) that could contradict each other. Here it is one enum, so "capturing
and busy at once" cannot happen. The media rule exists because of a real bug: the old ducker
resumed videos the user had paused on purpose.

**When:** the pad reducer emits `StartVoiceCapture` / `EndVoiceCapture`; the voice host turns
those into `BeginRequested` / `EndRequested` here. Speech-to-text results arrive as
`ProcessingFinished`. A max-length timer (`MAX_CAPTURE_TIMER`; 30 minutes for both commands and dictation, a guard against a recording left on) ends capture.

**How:**
- `reduce(state, event, config)` → `VoiceTransition { next, effects }`.
- Effects: `StartMic`, `StopMic`, `DuckMedia`, `RestoreMedia`, `ShowListening`, `ShowDictating`,
  `ShowThinking`, `ShowUnderstanding`, `HideOverlay`, `ScheduleHideOverlay`, `ClearStuckBusy`, `BeginProcessing { dictate, command_takeover }`, `SetTimer` / `CancelTimer`.
- Events: `BeginRequested`, `CancelRequested`, `EndRequested`, `ProcessingFinished`, `DictationEscalated` (live dictation heard a command mid-hold), `StuckBusyTimeout`, `Tick`.
- **Invariant 15:** the mic starts only on a successful begin (enabled + model ready).
- **Invariant 14:** `RunScript` and `AutoHotkey` never run from voice (`VoiceActionPolicy`).
- **Stuck-busy watchdog:** a session busy > 45 s is cleared on the next begin (or by an explicit `StuckBusyTimeout`); `Tick` never clears it.
- Dictation keeps the mic open through processing (live transcript); commands close it at once.

## Interface
Re-exports in `mod.rs`: `VoiceActionPolicy`, `MediaDuckPolicy`, `MediaPlayback`, and `reduce`, `VoiceEffect`, `VoiceEvent`, `VoiceSessionConfig`, `VoiceState`, `VoiceTransition`, `MAX_CAPTURE_TIMER`, `MAX_UTTERANCE`. `models`, `placement` and `self_check` are `pub` modules reached by path. Subfolder: [`command/`](./command/README.md).

| File | Contents |
|---|---|
| `mod.rs` | Module list and the re-exports above |
| `reducer.rs` | `VoiceState` (`Idle`, `Capturing`, `Busy`), `VoiceEvent`, `VoiceEffect`, `VoiceSessionConfig`, `VoiceTransition`, `reduce()`, `MAX_CAPTURE_TIMER`, `MAX_UTTERANCE` |
| `media_duck.rs` | `MediaDuckPolicy`: pause only what was playing; keyboard toggle only on a focused, playing YouTube |
| `action_policy.rs` | `VoiceActionPolicy::is_forbidden`: `RunScript` and `AutoHotkey` are forbidden from voice (matched ignoring case) |
| `models.rs` | `ModelFile`, `Group`, `files_for`, `url`, `speech_folder`: built-in model manifest; a download is used only when its SHA-256 matches |
| `model_files.rs` | `RELEASE`, `BASE_URL`, `FILES`: generated by `scripts/publish-models.ps1`. Not a module: `models.rs` pulls it in with `include!` |
| `placement.rs` | `PcFacts`, `Gpu`, `ModelSet` (`Light` shown as BASIC, `Balanced`, `Quality`), `Placement` (`Set`, `BelowFloor`, `NoDisk`), `place`, `DISK_SPARE_BYTES`, `QUALITY_GPU_BYTES`: which model set a PC gets |
| `self_check.rs` | `Timings`, `Outcome`, `decide`, `better`, `ratio`, `STT_LIMIT`, `BORDERLINE`, `POLISH_LIMIT_MS`: verdict from timing the models |

**Spoken commands** (`command/`): the deterministic router from a transcript to one button action,
the vocabulary it matches, the dictation-or-command classifier, and the safety and confirmation
policy that decides whether an action may run now, must be approved on the pad, or is refused.
See [`command/README.md`](./command/README.md).

## Invariants
- Session state is one enum, so capturing and busy cannot both hold (`reducer.rs`).
- Mic starts only on a successful begin (invariant 15); `RunScript` and `AutoHotkey` never run from voice (invariant 14); busy over 45 s is cleared on the next begin.
- Quality placement is a candidate only; the self-check can demote the PC to Balanced (`placement.rs`, `self_check.rs`).

## Side Effects
- None. `models::files_for` reads the built-in manifest only; nothing is downloaded here. Effects (`StartMic`, `DuckMedia`, timers, ...) are returned for the host.
